# src/shared: CONTRACTS (all teams depend on this)

Every change here can break the other teams. Read root `CLAUDE.md` §3 before touching anything.

| Contract | File |
|---|---|
| C1 domain models | `eduhub_shared/models/` (`account`, `analysis`, `generation`, `publishing`, `simulation`, `api`) |
| C2/C3 interfaces + errors | `eduhub_shared/interfaces.py`, `eduhub_shared/errors.py` |
| C4 HTTP API | `eduhub_shared/routes.py` → generated `contracts/openapi.json` (never edit by hand) |
| C5 metric formulas | `eduhub_shared/metrics.py` |
| C6 fixtures + fakes | `eduhub_shared/fixtures/` (generated by `fixtures/build.py`), `eduhub_shared/fakes.py` |
| Conformance helpers | `eduhub_shared/testing.py` (teams call these from their own tests) |

Rules for a change:
- Prefer **additive, backward-compatible changes**: new optional fields with defaults, new endpoints. Renaming or removing fields, changing types or semantics, or adding required request fields **breaks** another team. Agree on those first and list them under "Breaks" in the CHANGELOG.
- Versioning: patch for docs or descriptions, minor for additive changes, major for breaking changes.
- After editing, run all of these:
  ```bash
  python -m eduhub_shared.openapi && python -m eduhub_shared.fixtures.build && pytest src/shared
  ```
- Keep the fakes producing valid output for every model, and keep the fixtures realistic (in es-AR), because the front builds its UI from them.
